La Plantilla Base Universal (El Esqueleto)

Toda página web profesional parte de estas líneas esenciales. Incluyen soporte para tildes, ajuste automático a pantallas de celular y conexión a Tailwind CSS:

index.html 
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título de tu Proyecto</title>
    <!-- Tailwind CSS para diseño inmediato -->
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-slate-100 text-slate-900">

    <header class="bg-slate-900 text-white p-4">
        <h1 class="text-xl font-bold">Mi Empresa</h1>
    </header>

    <main class="max-w-4xl mx-auto p-6">
        <h2 class="text-2xl font-bold mb-2">Bienvenido</h2>
        <p>Contenido principal de la página.</p>
    </main>

</body>
</html>

Las 6 Piezas que Construyen Cualquier Web

1. Contenedores

Organizan la página en bloques lógicos.

  • <header> : Barra superior
  • <section> : Sección temática
  • <div> : Caja comodín
  • <footer> : Pie de página

2. Textos y Enlaces

Jerarquía de lectura y botones de navegación.

  • <h1> a <h3> : Títulos
  • <p> : Párrafos de texto
  • <a href="..."> : Enlace/Botón
  • <ul> / <li> : Listas

3. Formularios

Capturan datos del cliente para cotizar.

  • <form> : Bloque de envío
  • <input> : Caja de texto/número
  • <select> : Lista desplegable
  • <button> : Botón de acción

Cómo Ver tu HTML en un Repositorio Privado sin Publicarlo

Opción A (Automática)

Vercel / Cloudflare

Conecta tu cuenta de GitHub en vercel.com e importa tu repositorio privado (ej. E3LT27_01). Te da una URL privada gratuita que se actualiza en cada commit sin hacer público el repositorio.

Opción B (En iPhone)

Descarga Raw / Archivos

Entra al archivo .html en GitHub, toca los 3 puntos ... arriba a la derecha y elige Download. Ábrelo desde la app Archivos de iOS para verlo funcionar localmente.

Opción C (En Navegador)

Editor GitHub.dev

Cambia github.com por github.dev en la barra de direcciones de tu repositorio privado para abrir VS Code Web con previsualización instantánea.
