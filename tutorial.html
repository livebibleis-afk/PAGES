02

Configurar Permisos y Secretos en el Repositorio

Haz esto cada vez que quieras conectar un repositorio nuevo (ej. E3LT27_01).

2.1. Guardar los Secretos en el Repositorio

Ve a tu repositorio en GitHub: Settings → Secrets and variables → Actions → New repository secret y agrega:

  • Nombre: GEMINI_API_KEY → Pega tu clave AIzaSy...
  • Nombre: TELEGRAM_BOT_TOKEN → Pega el token de tu bot de Telegram.

*Nota: Si te sale "Failed to add secret, already exists", significa que ya está guardado. Para cambiarlo, toca el ícono del lápiz en la lista de secretos.

2.2. Activar Permisos de Escritura (Read and write permissions)

Dentro del repositorio, ve a Settings → Actions → General. Baja hasta el final a la sección Workflow permissions, selecciona Read and write permissions y presiona el botón Save.

2.3. Verificar que la pestaña Issues esté activa

En Settings → General, baja a la sección Features y asegúrate de que la casilla Issues esté marcada.

03

Crear el Motor .github/workflows/gemini.yml

Incluye 4 modelos en cascada (anti-error 503/429), filtro de archivos y envío del HTML renderizable a Telegram.

name: Gemini CLI

on:
  issues:
    types: [opened]
  issue_comment:
    types: [created]
  repository_dispatch:
    types: [telegram_prompt]

permissions:
  contents: write
  issues: write
  pull-requests: write

jobs:
  gemini:
    if: |
      github.event_name == 'repository_dispatch' ||
      (github.event_name == 'issues' && contains(github.event.issue.body, '@gemini-cli')) ||
      (github.event_name == 'issue_comment' && contains(github.event.comment.body, '@gemini-cli'))
    runs-on: ubuntu-24.04
    timeout-minutes: 5
    steps:
      - name: Descargar repositorio
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Analizar, editar archivos y responder
        env:
          GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          EVENT_NAME: ${{ github.event_name }}
          USER_PROMPT: ${{ github.event.client_payload.text || github.event.comment.body || github.event.issue.body }}
          CHAT_ID: ${{ github.event.client_payload.chat_id }}
          ISSUE_NUMBER: ${{ github.event.issue.number }}
        run: |
          cat << 'EOF' > agente.mjs
          import fs from "fs";
          import path from "path";
          import { execSync } from "child_process";

          async function sendTelegram(chatId, text) {
            const token = (process.env.TELEGRAM_BOT_TOKEN || "").trim();
            if (!token || !chatId) return;
            await fetch(`https://api.telegram.org/bot${token}/sendMessage`, {
              method: "POST",
              headers: { "Content-Type": "application/json" },
              body: JSON.stringify({ chat_id: chatId, text: text.slice(0, 4000) })
            });
          }

          // Envía archivos HTML directamente a Telegram para visualizarlos sin publicar el repo
          async function sendTelegramDocument(chatId, filePath) {
            const token = (process.env.TELEGRAM_BOT_TOKEN || "").trim();
            if (!token || !chatId || !fs.existsSync(filePath)) return;
            try {
              const formData = new FormData();
              formData.append("chat_id", chatId);
              const content = fs.readFileSync(filePath);
              const blob = new Blob([content], { type: "text/html" });
              formData.append("document", blob, path.basename(filePath));
              formData.append("caption", `📄 Vista previa lista: toca el archivo ${path.basename(filePath)} para abrirlo en tu pantalla.`);
              await fetch(`https://api.telegram.org/bot${token}/sendDocument`, {
                method: "POST",
                body: formData
              });
            } catch (e) {}
          }

          async function callGeminiWithFallback(apiKey, promptText) {
            const models = [
              "gemini-2.5-flash",
              "gemini-2.0-flash",
              "gemini-2.5-pro",
              "gemini-1.5-flash"
            ];
            let lastError = null;

            for (const model of models) {
              const url = `https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent?key=${apiKey}`;
              for (let attempt = 1; attempt <= 3; attempt++) {
                try {
                  const res = await fetch(url, {
                    method: "POST",
                    headers: { "Content-Type": "application/json" },
                    body: JSON.stringify({
                      contents: [{ parts: [{ text: promptText }] }],
                      generationConfig: { responseMimeType: "application/json" }
                    })
                  });

                  const data = await res.json();
                  if (res.ok) return { data, modelUsed: model };

                  lastError = `(${res.status}) en ${model}: ${JSON.stringify(data)}`;
                  if (res.status === 404 || res.status === 400) break;

                  if (res.status === 503 || res.status === 429) {
                    await new Promise(r => setTimeout(r, attempt * 4000));
                    continue;
                  }
                } catch (err) {
                  lastError = err.message;
                  await new Promise(r => setTimeout(r, 3000));
                }
              }
            }
            throw new Error(`Servidores ocupados. Último error: ${lastError}`);
          }

          async function main() {
            try {
              const apiKey = (process.env.GEMINI_API_KEY || "").trim();
              const userPrompt = process.env.USER_PROMPT || "";
              const promptLower = userPrompt.toLowerCase();
              const files = execSync("git ls-files").toString().trim().split("\n").filter(Boolean);
              let context = "Lista de archivos en el repositorio:\n" + (files.length ? files.join("\n") : "(Repositorio vacío)") + "\n\n";

              let matchedFiles = files.filter(f => promptLower.includes(f.toLowerCase()));
              for (const f of matchedFiles) {
                if (/\.(json|html|js|ts|css|py|md|yml|yaml|svg)$/i.test(f) && !f.includes("package-lock")) {
                  try {
                    const content = fs.readFileSync(f, "utf8").slice(0, 25000);
                    context += `\n--- Contenido actual de ${f} ---\n${content}\n`;
                  } catch (e) {}
                }
              }

              const systemInstruction = `Eres el ingeniero desarrollador principal de este repositorio. Responde siempre en español.
          Si el usuario solo hace una pregunta, respóndela en "reply" y deja "filesToUpdate" vacío [].
          Si te pide editar, corregir o crear un archivo, incluye el código COMPLETO y funcional en "filesToUpdate".

          Responde ÚNICAMENTE con un JSON válido con esta estructura:
          {
            "reply": "Explicación clara de los cambios realizados",
            "commitMessage": "Mensaje corto del commit",
            "filesToUpdate": [
              { "path": "archivo.html", "content": "código completo" }
            ]
          }`;

              const promptText = `${systemInstruction}\n\nInstrucción del usuario: ${userPrompt}\n\n${context}`;
              const { data, modelUsed } = await callGeminiWithFallback(apiKey, promptText);
              const rawText = data.candidates?.[0]?.content?.parts?.[0]?.text || "{}";
              const result = JSON.parse(rawText);
              let replyMsg = `${result.reply || "Proceso completado."}\n\n🤖 Modelo: ${modelUsed}`;
              const updatedList = [];

              if (Array.isArray(result.filesToUpdate) && result.filesToUpdate.length > 0) {
                for (const fileObj of result.filesToUpdate) {
                  if (fileObj.path && typeof fileObj.content === "string") {
                    const dir = path.dirname(fileObj.path);
                    if (dir && dir !== ".") fs.mkdirSync(dir, { recursive: true });
                    fs.writeFileSync(fileObj.path, fileObj.content, "utf8");
                    updatedList.push(fileObj.path);
                  }
                }

                if (updatedList.length > 0) {
                  execSync('git config user.name "github-actions[bot]"');
                  execSync('git config user.email "41898282+github-actions[bot]@users.noreply.github.com"');
                  for (const p of updatedList) execSync(`git add "${p}"`);
                  const status = execSync("git status --porcelain").toString().trim();
                  if (status) {
                    const msg = (result.commitMessage || "Actualización vía Bot").replace(/"/g, "'");
                    execSync(`git commit -m "${msg}"`);
                    execSync("git push");
                    const sha = execSync("git rev-parse --short HEAD").toString().trim();
                    replyMsg += `\n✅ Cambios publicados (Commit: ${sha})\nArchivos: ${updatedList.join(", ")}`;
                  }
                }
              }

              fs.writeFileSync("respuesta.txt", replyMsg);
              if (process.env.EVENT_NAME === "repository_dispatch" && process.env.CHAT_ID) {
                await sendTelegram(process.env.CHAT_ID, replyMsg);
                for (const p of updatedList) {
                  if (p.toLowerCase().endsWith(".html")) {
                    await sendTelegramDocument(process.env.CHAT_ID, p);
                  }
                }
              }
            } catch (err) {
              const errMsg = `⚠️ Error: ${err.message}`;
              fs.writeFileSync("respuesta.txt", errMsg);
              if (process.env.EVENT_NAME === "repository_dispatch" && process.env.CHAT_ID) {
                await sendTelegram(process.env.CHAT_ID, errMsg);
              }
            }
          }

          main();
          EOF

          node agente.mjs
          rm -f agente.mjs
          if [ "$EVENT_NAME" != "repository_dispatch" ] && [ -n "$ISSUE_NUMBER" ]; then
            gh issue comment "$ISSUE_NUMBER" --body-file respuesta.txt
          fi

Puente Telegram en Google Apps Script (Multi-Repo)

Permite controlar PAGES y E3LT27_01 desde el mismo bot de Telegram.

const GITHUB_TOKEN = 'PEGA_AQUI_TU_GITHUB_PAT_TOKEN'; // Empieza con github_pat_...
const GITHUB_OWNER = 'livebibleis-afk';

function doPost(e) {
  try {
    const contents = JSON.parse(e.postData.contents);
    if (!contents.message || !contents.message.text) return;

    const chatId = contents.message.chat.id;
    let text = contents.message.text.trim();

    // Repositorio por defecto: PAGES
    // Si el mensaje empieza con #e3 o /e3, envía la orden al repositorio E3LT27_01
    let targetRepo = 'PAGES';
    if (/^([#/]e3|e3lt27_01)\b/i.test(text)) {
      targetRepo = 'E3LT27_01';
      text = text.replace(/^([#/]e3|e3lt27_01)\s*/i, '');
    }

    const url = `https://api.github.com/repos/${GITHUB_OWNER}/${targetRepo}/dispatches`;
    const payload = {
      event_type: 'telegram_prompt',
      client_payload: {
        text: text,
        chat_id: String(chatId)
      }
    };

    UrlFetchApp.fetch(url, {
      method: 'post',
      headers: {
        'Authorization': 'Bearer ' + GITHUB_TOKEN,
        'Accept': 'application/vnd.github+json',
        'X-GitHub-Api-Version': '2022-11-28'
      },
      contentType: 'application/json',
      payload: JSON.stringify(payload),
      muteHttpExceptions: true
    });
  } catch (err) {
    console.error(err);
  }
}
Regla de Oro al actualizar Google Apps Script:

Cada vez que cambies el GITHUB_TOKEN o agregues un repositorio nuevo en Apps Script, ve a Implementar → Gestionar implementaciones → Ícono del Lápiz (Editar) → Versión: Nueva versión → Implementar. Así los cambios entran en vigor al instante sin cambiar la URL del Webhook.

Cómo Enviar Órdenes y Ver HTML en Repositorios Privados

Comandos listos para usar y cómo previsualizar sin publicar en GitHub Pages.

Modos de Disparo

1. En Telegram hacia PAGES (por defecto): Mejora el archivo Wilsonservicios.html agregando una galería de obras.
2. En Telegram hacia E3LT27_01 (prefijo #e3): #e3 Crea el archivo index.html con diseño moderno en Tailwind CSS.
3. Desde un Issue en GitHub: @gemini-cli Revisa el código de index.html y optimiza el formulario.

Ver HTML si el Repositorio es Privado

  • Automático en tu Telegram (Ya incluido en el Paso 3): El gemini.yml de este tutorial detecta cuando se crea o edita un archivo .html y te lo envía adjunto al chat de Telegram. Solo tócalo en tu celular para verlo renderizado a pantalla completa sin publicarlo.
  • Vercel / Cloudflare Pages Gratis: Puedes conectar E3LT27_01 en vercel.com manteniendo el repositorio privado en GitHub.
  • Descarga local en iPhone/PC: Abre el archivo en GitHub, toca los tres puntos ... → Download y ábrelo desde la app Archivos o Safari.
