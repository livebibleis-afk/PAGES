Se compactó el JSON original (esquema Aquifer, un objeto por versículo
con marcado HTML) a un archivo por libro, con solo el texto de cada
versículo, para cargar cada libro bajo demanda. Se conservó la
ortografía de 1909 (á, fué, crió, etc.). La tipografía en mayúsculas
de la palabra inicial de algunos capítulos (EN, EMPERO, JEHOVÁ) se
pasó a caja de oración (En, Empero, Jehová) para la práctica.

Estos archivos se incluyen junto a la página para uso local; no se
consulta ninguna API externa al memorizar.
