# E3LT27 v2 — demo temporal (openPlan3D)

Vista 2D/3D de la casa E3LT27 hecha con [openPlan3D](https://github.com/laanlabs/openPlan3D)
(© 2026 theLodgeStudio, licencia MIT — ver `LICENSE-openPlan3D.txt`).

Build estático (SvelteKit + adapter-static) con el plano `E3LT27_openplan3d.json` precargado.
Al abrir la página se importa el plano en el navegador y se abre el editor en 3D.
`?home=1` muestra la biblioteca de proyectos. Publicación temporal.
