## 📁 Estructura del repositorio

```text
PAGES/
├── index.html          # Landing principal EXEL
├── README.md
├── assets/             # Imágenes, favicon y recursos estáticos
├── css/ · js/          # Estilos y scripts compartidos (si se usan)
├── portafolio/         # Proyectos, visores 3D y herramientas de muestra
│   ├── casas-del-valle/
│   ├── casas-del-valle-3d/
│   ├── casa/
│   ├── e3lt27/
│   └── ...
├── clientes/           # Sitios de negocios locales
│   ├── wilson-servicios/
│   ├── carlos-guerra/
│   ├── antojos/
│   └── ...
├── demo/ · demos/      # Redirecciones a las rutas nuevas (enlaces antiguos)
└── .github/            # Workflows (Gemini CLI, etc.)
```

Las rutas antiguas en la raíz (`casa.html`, `antojos.html`, …) y en `demo/` / `demos/` redirigen a la carpeta nueva, para que los enlaces ya compartidos sigan funcionando.
